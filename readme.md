
* ABC Website Project

* Project Title:
Learn ABC Website

* Description:
This project is a simple educational website created using **HTML, CSS, and JavaScript**.  
It helps children learn the English alphabet (A-Z) with images of objects.

Each letter displays:
1. Alphabet Letter
2. Related Word
3. Image
4. Next Button to move to next alphabet

Example:
1. A → Apple
2. B → Banana
3. C → Cat
4. D → Dog
